# Консольный мульти-бот на Python

Многофункциональный консольный бот, который объединяет несколько полезных инструментов в одном интерфейсе.

## Возможности

- **Курс валют** — получает актуальные курсы с API Центробанка РФ.
- **Заметки** — добавление, просмотр и удаление заметок с сохранением в JSON.
- **Игра «Угадай число»** — классическая игра на угадывание числа с подсказками.

## Технологии

- Python 3.10+
- `requests` — для работы с API
- `json` — для хранения заметок
- `random` — для игры

## Установка и запуск

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/shizafal/console-bot.git
   ```

2. Перейди в папку:
   ```bash
   cd console-bot
   ```

3. Установи зависимости:
   ```bash
   pip install requests
   ```

4. Запусти бота:
   ```bash
   python main.py
   ```

## Использование

После запуска введи одну из команд:

| Команда | Что делает |
|---------|------------|
| `help` | Показать список команд |
| `course` | Курс валют (запросит код валюты и сумму) |
| `note` | Заметки (меню: добавить, показать, удалить) |
| `game` | Игра «Угадай число» |
| `exit` | Выход |

### Пример работы

```
=== Консольный мульти-бот ===
Введите 'help' для списка команд.

> course
Введите код валюты: USD
Введите количество USD: 100
100.0 USD = 8647.3 RUB

> note
--- Добро пожаловать в заметки ---
1. Добавить заметку
2. Показать все заметки
3. Удалить заметку
4. Назад
```
